# House rules

Requirements every experiment meets. They were each asked for
explicitly, and they are not stylistic preferences to be re-litigated.

The numbers are **permanent**. They are cited from source comments and
from past conversations, so a rule is never renumbered - only the note
explaining it moves. A retired rule keeps its number and says it is
retired.
