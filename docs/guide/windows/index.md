# The windows

Double-click the **SMUniversal Lab Suite** icon on the desktop. A window
opens with one card per measurement; click a card to open that window.
Each measurement window takes charge of the instruments it connects to,
so two windows cannot drive one instrument at once. While one window
holds the instruments, the other measurement cards are greyed out and
only the plotter opens.

The header, the **Instruments** panel, **Run** and **Stop**, and the
results table work the same way in every window. They are described once,
on [Every window](every-window.md).

| Window | What it is for | Guide |
|---|---|---|
| **IV sweep** | Current-voltage sweeps of a device, once or repeated on a schedule, with a linear fit for ohmic samples. | [IV sweep](iv-sweep.md) |
| **Van der Pauw + Hall** | Sheet resistance from four corner contacts, then carrier density and mobility in a field. One mounted sample, one session. | *coming* |
| **Fixed sourcing vs time** | Hold one voltage or current and log the response over time. | *coming* |
| **Ossila 4-point probe** | Sheet resistance and resistivity through the Ossila four-point probe head, corrected for sample geometry. | *coming* |
| **Plot saved data** | Open files saved by any window to plot them, compare their settings and export the data. | *coming* |

## Closing a window

Close it with its own close button, top right. That is what switches the
instrument's output off and releases it for the next window. If anything
in the results table has not been saved, you are asked first. Nothing is
saved automatically.
