# Open items

State, not reference. Short, high churn, and some of it generated.

| Note | Kind |
|---|---|
| [checkup-owed](checkup-owed.md) | generated from git history |
| [Known technical debt](technical-debt.md) | hand-written |

**Only what is open belongs here.** A page that has become mostly
description of a thing that works is reference, and reference lives in
`docs/architecture/` or the instrument note — the open tail moves to
technical debt as ordinary entries. `direct-gpib-usb-hs.md` sat here
until 2026-08-27 with about four-fifths of it describing a commissioned
transport, which is how a folder meant to be scanned for open questions
becomes one nobody scans.

The rule that earns this folder: **record open items rather than quietly
fixing or ignoring them**, and say plainly when something is unverified
against hardware. An open question buried in the middle of a reference
document is one nobody finds when they are in a position to answer it.
