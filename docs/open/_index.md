# Open items

State, not reference. Short, high churn, and some of it generated.

| Note | Kind |
|---|---|
| [[checkup-owed]] | generated from git history |
| questions for the lab | hand-written |
| unverified against hardware | hand-written |
| technical debt | hand-written |

The rule that earns this folder: **record open items rather than quietly
fixing or ignoring them**, and say plainly when something is unverified
against hardware. An open question buried in the middle of a reference
document is one nobody finds when they are in a position to answer it.
